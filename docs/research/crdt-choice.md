## Gotchas (all three)

- **Do not** `updateText`/`text.update`/Myers against *current* CRDT vs new git blob. Agent blob is based on last commit. Replay **at last-git heads/frontiers**, then merge concurrent browser ops. 2-way “current vs new” fights live edits.
- ProseMirror/Tiptap bindings store structured XML/blocks, not vanilla markdown. For this product use **CodeMirror 6** (or a markdown WYSIWYG that binds to a string).
- Comment ranges: store two cursors (anchor/head) out-of-band. Deleted text → Automerge cursor moves; Yjs may return `null`.
- Automerge `updateText` is **experimental**. Loro `applyDiff` ≠ git diff. Yjs default GC deletes the history you need for git mapping.

## Recommendation

Pick **Automerge 3.5** for this product. The webhook path is `changeAt(lastGitHeads, d => updateText(d, ['text'], newBlob))` plus `getCursor` for server-side comments and `getAuthors` for `Co-authored-by` — one library, no extra diff stack. Keep the CRDT as a plain string; bind **CodeMirror** (`@automerge/automerge-codemirror`), not ProseMirror. Persist Automerge heads next to the last Git SHA. **Loro 1.16** is the right swap if the live-copy server must be Rust-only (native crate, snapshots, `text.update` + checkout) — same architecture, you write the WS layer. **Skip Yjs** here: best ecosystem (Hocuspocus/y-sweet/y-codemirror) but default GC, no `changeAt`, and manual git-diff replay are the opposite of “Git is SoT, CRDT is a working copy.”
